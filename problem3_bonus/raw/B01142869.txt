class Solution:
    def xorAfterQueries(self, nums: List[int], queries: List[List[int]]) -> int:
        for q in queries:
            idx = q[0]

            while idx <= q[1]:
                nums[idx] = (nums[idx] * q[3]) % (10**9 + 7)
                idx += q[2]

        xor = 0
        for num in nums:
            xor = xor ^ num

        return xor

This problem gave me an explicit set of instructions, telling me "For each query, you must apply the following operations in order:

Set idx = li.
While idx <= ri:
Update: nums[idx] = (nums[idx] * vi) % (109 + 7)
Set idx += ki."

With this, the time complexity starts off at O(n * k) where n is the number of queries, and k is the largest value of a query's ri value. After this, the question tells me to return the bitwise XOR of all elements in nums after the queries. To do this, I initialize an xor variable with the value 0, since 0 XOR (any number) equals this number, for example 0000 (0 in 4 bit binary) ^ 1010 (4 in 4 bit binary) equals 1010 (4 in 4 bit binary), where the output has a 1 for each bit where it differs, 1 differs from 0, so each place with a 1 is preserved. Then, I loop through the nums array, and apply the XOR function to the previous value and the current number. Finally, I return the result, which I saved as variable "xor". The part of the solution that I wrote was O(j), where j is the length of the nums array, because we iterate through it once.
