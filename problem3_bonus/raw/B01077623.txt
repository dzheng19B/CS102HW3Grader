class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        cols = len(encodedText) // rows
        result = ""

        for i in range(cols):
            x = 0
            y = i

            while x < rows and y < cols:
                result = result + encodedText[x * cols + y]
                x = x + 1
                y = y + 1
        return result.rstrip(" ")

This solution will reconstruct the decoded message in O(n) time complexity where n is the length of encodedText and the space complexity is also O(n) with the result of the string. Through first determining the number of columns, iterating through each starting column and traversing diagonally right while increasing the row and column indexes. And at each step, it will calculate the correct index in the original string with x * cols * y to append the character to the result. The return result.rstrip(" ") takes away any spaces to return the message.
