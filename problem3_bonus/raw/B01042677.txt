class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        dicton = {} # mmm map
        for i in range(len(nums)):
            if nums[i] not in dicton:
                dicton[nums[i]] = [] # make array at nums[i] in dicton to store copies
            dicton[nums[i]].append(i) # put i as entry

        minDist = -1 # in case find nothing
        for pos in dicton.values(): # just the lists
            if len(pos) >= 3: # skip non triples
                for i in range(len(pos) - 2): # -2 to avoid out of bounds
                    first = pos[i]
                    third = pos[i+2]
                    dist = 2*(third-first)
                    if minDist == -1 or dist < minDist:
                        minDist = dist
        return minDist


I believe this solution to be time complexity n. The reason for this is that the time spent should scale linearly with n for a few reasons. The first loop goes through each term in nums once. The second loop is technically a nested loop but since each element gets added to the dictionary only one time the inner loop should only see each element of nums one time ever (across all iterations of the outer loop) so it's really more like just looping through nums more times separately, which while it makes this problem a multiple of n, we remove constant multiples and thus can still call this an O(n) time. The way this solves the problem is by making a dictionary in python and for every new element making a new list entry in that dictionary and adding it. Then every time it sees a repeat of that element in the future it adds that element to the list. Then we establish the minimum distance if nothing else fits as -1 for edge cases and go through the dictionary and look at each list that's got at least 3 elements (since below that there can't be a tuple by definition). Since the middle element gets cancelled out in the distance formula, it turns out you can just look at the sets of 3 and, specifically take the third minus the first twice (since k-i happens twice if you simplify the distance formula to 2(k-i)) to get the distance. You then simply compare it to the minimum distance, and if either the current one is less or you haven't found a real distance yet (hence checking if it's -1), you set the current distance to our new minimum distance for now. Once we check all the sets of 3 in these lists, we end the for loop and return the minimum distance we found.
