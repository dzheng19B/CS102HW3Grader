class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        positions = {}
        ans = float('inf')

        # Store all positions of each number
        for i, num in enumerate(nums):
            if num not in positions:
                positions[num] = []
            positions[num].append(i)

        # Check every consecutive group of 3 equal elements
        for indices in positions.values():
            if len(indices) >= 3:
                for i in range(len(indices) - 2):
                    ans = min(ans, 2 * (indices[i + 2] - indices[i]))

        return -1 if ans == float('inf') else ans



This solution runs in O(n) time because we make one pass through the array to store the positions of each number in a hash map, and then another pass through all stored indices to check groups of three consecutive equal elements. Since each index is processed only a constant number of times, the total work is linear in the size of the array.

The solution works by first storing every position where each number appears in the array. For example, if the number 5 appears at indices [1, 4, 7], we save those positions together.
Then, for each number that appears at least 3 times, we check every group of 3 consecutive positions and calculate the distance using the first and third index. By checking all such groups, we can find the smallest possible distance.
