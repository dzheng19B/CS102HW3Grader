class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        result = float('inf')
        for num in set(nums):
            
            indces = [i for i in range(len(nums)) if nums[i] == num]
            for m in range(len(indces) - 2):
                result = min(result, 2 * (indces[m + 2] - indces[m]))
        if result != float('inf'):

            return result 
        else:
            return -1



It's o(n) time because there is an other loop over the array. Every element is ran over a constant number of times. This solution solves by collecting indices and their triplets. Thus using the min across all valid triplets we can check the minimum distance foundor -1 if no value appeared at least 3 times.
