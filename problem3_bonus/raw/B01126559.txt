class Solution(object):
    def minimumDistance(self, nums):
        positions = {}
        
        for i in range(len(nums)):
            val = nums[i]
            if val not in positions:
                positions[val] = []
            positions[val].append(i)
        
        ans = -1 
        
        for val in positions:
            idxs = positions[val]
            
            if len(idxs) < 3:
                continue
            
            for i in range(len(idxs) - 2):
                distance = 2 * (idxs[i + 2] - idxs[i])
                
                if ans == -1 or distance < ans:
                    ans = distance
        
        return ans

time complexity of O(n^2) but since constraint is that num.lengh is <= 100 time complexity will never actually be that big at least in the context of this problem.
this solves the problem because what this code does is it groups the indices of every equal value, but it will only check the values that appear 3 times, then it will check which has the smallest possible span of those values that appear 3 times. and i also managed to shorten down the formula because i realized the index of the 2nd occurrence of the number doesnt actually matter in the end, and this also made it so i didnt actually have to check every truple in my 2d array, only consecutive ones so i just used a sliding window of size 3
