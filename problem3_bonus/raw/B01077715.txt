class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        if len(nums) < 3:
            return -1
        mn = -1

        dist = {}
        
        for i, val in enumerate(nums):
            if val in dist:
                dist[val].append(i)
            else:
                dist[val] = [i]
        
            
        for key, val in dist.items():
            if len(val) < 3:
                continue
            i = 0
            i1 = 2

            while (i1 < len(val)):
                tmp = 2*(val[i1] - val[i])
                if tmp < mn or mn == -1:
                    mn = tmp
                i+=1
                i1+=1
          
        return mn

problem:
https://leetcode.com/problems/minimum-distance-between-three-equal-elements-ii

explanation:
the solution is O(n). it does two big passes over collections with size <= n, all linear. the indices i, j, k monotonically increase, so we can simplify the distance calculation like follows:
 abs(i - j) + abs(j - k) + abs(k - i)
 j - i + k - j + k - i
 - i - i + k + k
 2(k-i)

 we remove the dependency on j, so we no longer have to perform a naive search on i, j, and k. to satisfy the condition of nums[i] == nums[j] == nums[k], we reform the statement as 'nums[i] == nums[j] and there exists a j such that i /= j /= k and nums[j] == nums[i], in other words, if nums[i] and nums[j] == 1, there must be one other 1 <=> there must be at least 3 ones. our dict tracks the indices, and implicity the amount of each number that exists in our array.
