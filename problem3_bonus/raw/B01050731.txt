Time complexity is O(n) as we do one pass to group indices and another pass over index triples. O(n) space complexity due to using defaultdict, which I found to automatically create an empty list for any key accessed for the first time. More convenient I think. We are first building the dictionary mapping each value to all the positions it appears in. We make sure to skip values that appear less than 3 times and then use sliding window technique for 4 consecutive indices. Finally, we track minimum and handle the case where there isn't any valid tuples.
